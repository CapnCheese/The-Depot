The first game me and my friends have made - hopefully more to come.

Short little game about shipping and whatnot - made for the Bad Ideas game jam of March of 2026.

There is technically 7 endings. Try to find them all! (an ending is denoted by the black screen)

Controls (forgot to add in game):

WASD: Move

Space: Jump

Mouse: Look

Control / C : Crouch

E: Pick up

G: Drop

R: Reload

Z: Zoom

Click: Fire
